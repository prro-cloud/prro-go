# Безпека

## Підтримувані версії

Виправлення безпеки виходять для останньої мінорної версії.

## Як повідомити про вразливість

Не створюйте публічний issue. Повідомте приватно одним зі способів:

- [GitHub Security Advisories](https://github.com/prro-cloud/prro-go/security/advisories/new);
- лист на [support@prro.cloud](mailto:support@prro.cloud) з темою «Security».

Опишіть вразливість, версію бібліотеки і кроки відтворення. Не додавайте
справжніх токенів, секретів вебхуків і персональних даних покупців.

Ми підтвердимо отримання протягом 3 робочих днів і повідомимо про
виправлення.

## Що варто знати

- Токен API і секрет вебхука — облікові дані: зберігайте їх як паролі, не
  комітьте в репозиторій.
- Перевіряйте підпис кожної доставки вебхука (`webhook.Verify` або
  `webhook.Handler`) до будь-якої обробки тіла.
- Бібліотека не пише токени й тіла запитів у журнал.
